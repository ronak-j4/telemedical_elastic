Workload 1 — Dashboard Aggregations

All five dashboard GROUP-BY queries execute in a single Elasticsearch aggregation round-trip — no repeated full-table scans on Oracle.

Workload 2 — Free Text Search

BM25 relevance ranking, fuzzy matching and hit highlighting on clinical text. Oracle can only do slow full-table LIKE '%…%' scans.

Workload 3 — Doctor Attribute Lookup

Find doctors by specialization, experience, rating and city — all from a single denormalized document. Oracle requires 5 JOINs across DOCTOR, DOCTOR_SPECIALIZATION, DOCTOR_RATING, HOSPITAL_DOCTOR and HOSPITAL.

Workload 4 — Geo-Proximity Hospital Finder

Elasticsearch geo_point + geo_distance filter finds hospitals within a radius and sorts by actual distance. Oracle Free Edition has no spatial index — it can only match by city name.
